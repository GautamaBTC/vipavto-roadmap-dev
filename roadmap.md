# Дорожная карта разработки лендинга "VipАвто"

Этот документ описывает пошаговый план создания нового веб-сайта для автосервиса "VipАвто".

### Этап 1: Основа и структура проекта

- [ ] Создать базовую структуру каталогов: `css/`, `js/`, `img/`, `fonts/`.
- [ ] Создать основные файлы: `index.html`, `css/style.css`, `js/main.js`.
- [ ] Подключить шрифты (Inter) и базовые стили в `index.html`.
- [ ] Создать файл `.htaccess` для будущей конфигурации сервера.

### Этап 2: HTML-разметка

- [ ] Создать семантическую разметку для `index.html`.
- [ ] Добавить разметку для шапки (Header) с логотипом, навигацией и кнопкой переключения темы.
- [ ] Добавить разметку для главного экрана (Hero Section) с заголовком, подзаголовком и кнопкой.
- [ ] Добавить разметку для секции "Услуги" с карточками.
- [ ] Добавить разметку для секции "Преимущества" с карточками.
- [ ] Добавить разметку для секции "Отзывы".
- [ ] Добавить разметку для секции "Контакты" с картой и контактной информацией.
- [ ] Добавить разметку для футера (Footer).
- [ ] Добавить разметку для модального окна с формой записи.

### Этап 3: CSS - Стилизация и дизайн

- [ ] В `style.css` определить CSS-переменные для двух тем (светлой и тёмной): цвета, шрифты, тени, радиусы.
- [ ] Реализовать базовые стили (reset, body, typography).
- [ ] Стилизовать все секции и компоненты с подходом **Mobile-First**.
- [ ] Реализовать адаптивный дизайн с помощью медиа-запросов для планшетов и десктопов.
- [ ] Добавить плавные `transition` для всех интерактивных элементов (кнопки, ссылки, карточки).
- [ ] Реализовать стили для кастомного `:focus`, убирающие стандартное свечение.
- [ ] Стилизовать и скрыть модальное окно по умолчанию.

### Этап 4: JavaScript - Интерактивность и анимации

- [ ] В `main.js` написать скрипт для переключения между светлой и тёмной темой.
- [ ] Реализовать логику открытия/закрытия мобильного "бургер-меню".
- [ ] Добавить плавную анимацию для иконки "бургера" (превращение в крестик).
- [ ] Реализовать открытие и закрытие модального окна с формой.
- [ ] Написать скрипт для анимации появления элементов при прокрутке (scroll-triggered animations) с помощью `Intersection Observer API`.
- [ ] Реализовать анимацию "счетчика" для цифр в секции "Преимущества".

### Этап 5: Ассеты и финальная оптимизация

- [ ] Подобрать и интегрировать фоновое видео для Hero Section.
- [ ] Подобрать и добавить качественные SVG-иконки для услуг и преимуществ.
- [ ] Оптимизировать все изображения (конвертация в WebP, `loading="lazy"`).
- [ ] Минифицировать файлы `style.css` и `main.js` (опционально, для продакшена).
- [ ] Настроить `.htaccess` для кэширования и сжатия (Gzip).
- [ ] Провести финальное тестирование на разных устройствах и браузерах.
